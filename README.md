### 💻 Local Development

Clone the repository:

```bash
git clone https://github.com/ferial29/shams-technology.git
cd shams-technology
npm install
```

Create a `.env.local` file with the required environment variables for email functionality.

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
